# Magin199 Farmer Visual

Ресурс-пак для Minecraft Java 1.16.5 Forge. Текстура меча сделана по присланному образцу: фиолетово-розовое лезвие, чёрная рукоять и розовый акцент.

## Установка
1. Скачай репозиторий как ZIP.
2. Помести ZIP или папку пакета в `.minecraft/resourcepacks`.
3. Включи пакет в настройках ресурсов.
4. Для автоматического применения текстуры к мечу с именем **Farmer** нужен OptiFine либо совместимый CIT-мод для Forge 1.16.5.
5. Назови меч `Farmer` в наковальне (или `Фармер`, если используешь русское имя).

Minecraft без CIT не умеет автоматически выбирать текстуру по пользовательскому зачарованию.

Версия: 1.16.5, pack_format 6.
